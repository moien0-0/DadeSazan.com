      پایگاه داده هنوز راه‌اندازی نشده است
      
ثبت‌نام شما در سیستم احراز هویت انجام شده، اما جداول تیم هنوز ساخته نشده‌اند. فقط یک بار این مراحل را انجام دهید:

      
    
        
  1. وارد supabase.com/dashboard شوید و پروژه خود را باز کنید.
    2. 
        
  2. از منوی سمت چپ: SQL Editor → دکمه New query.
    3. 
        
  3. کل محتوای فایل setup.sql (داخل پوشه supabase) را Paste و دکمه Run را بزنید.
    4. 
        
  4. به همین صفحه برگردید، صفحه را رفرش کنید و با همان ایمیل و رمز، وارد شوید.
    5. 
      

    


    

      
      
      
    


    
    

      

        
        
        

      

      

        
        

          
          
        

        

      

      

      
      
      

      

        رمز را فراموش کرده‌اید یا پیام «ایمیل قبلاً ثبت شده» می‌بینید؟
        
این یعنی ایمیل شما در سیستم ثبت شده اما رمزش را نمی‌دانید. هیچ ایمیلی ارسال نمی‌شود؛ چون مالک پروژه خودتان هستید، با یکی از دو روش زیر در کمتر از یک دقیقه رمز جدید بسازید:

        
روش ۱ — داشبورد: supabase.com/dashboard → پروژه‌تان → Authentication → Users → روی ایمیل خود کلیک کنید → Generate new password → رمز جدید را کپی و با همان وارد شوید.

        
روش ۲ — SQL Editor (مطمئن‌ترین): داشبورد → SQL Editor → New query → کد زیر را اجرا کنید؛ فقط RAMZ_JADID را رمز دلخواه خودتان و ایمیل را ایمیل خودتان کنید:

        
create extension if not exists pgcrypto;
update auth.users
set encrypted_password =
  crypt('RAMZ_JADID', gen_salt('bf'))
where email = 'YOU@example.com';

        
سپس صفحه را رفرش کنید و با ایمیل + رمز جدید وارد شوید. اگر ترجیح می‌دهید از صفر ثبت‌نام کنید، به‌جای دو دستور بالا این یک خط را اجرا کنید تا حساب قبلی پاک شود: delete from auth.users where email = 'YOU@example.com';

      

      
حساب ندارید؟ از تب «ثبت‌نام» شروع کنید.
